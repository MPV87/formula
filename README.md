# Formula®

Onepager für die Marke Formula® (KP Plattner GmbH) – reine Marken- und Produktinfo, kein Shop.

- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – Rechtliches
- `img/sortiment/` – Produktfotos (WebP)
- `fonts/` – Playfair Display und Montserrat, lokal eingebunden (OFL-Lizenz)
- `og-image.jpg` – Vorschaubild beim Teilen in Social Media / Messengern
